# Pacific Spirit Electrical

A static-first Astro website for Pacific Spirit Electrical in Vancouver, British Columbia.

## Run locally

Install dependencies, then start the development server:

```sh
npm install
npm run dev
```

Astro will show the local URL in the terminal (normally `http://localhost:4321`).

## Build for production

```sh
npm run build
```

The static production site is generated in `dist/`. To inspect that build locally:

```sh
npm run preview
```

## Logo and favicon

The approved logo is at `public/images/pacificspiritelectrical_logo.png`. It is used in the shared header/footer component and Open Graph metadata. `public/favicon.png` is generated from the original logo asset. If the logo asset is replaced, update the dimensions in `src/components/Brand.astro` and `src/components/SeoHead.astro`, then regenerate the favicon.

Do not recreate or alter the supplied logo; use the original approved asset.

## Updating business information

The confirmed business details are centralized in `src/data/site.ts`. Update this file for the business name, email, website, service area, or location. Service cards are also defined in that file.

SEO metadata is defined per page in `src/pages/`. LocalBusiness structured data is generated by `src/components/SeoHead.astro` using the values in `src/data/site.ts`.

## Adding a phone number later

Once a phone number is confirmed, add it to `src/data/site.ts`. Then update `src/components/Header.astro` and `src/components/Footer.astro` with `tel:` links, and replace the `mailto:` link in the `.mobile-contact` element in `src/components/Footer.astro` with a click-to-call button. Add the same number to the LocalBusiness schema in `src/components/SeoHead.astro`.

## Connecting the form

The form UI and browser submit handler live in `src/pages/contact.astro`. The browser posts to the same-origin `/api/quote` endpoint, which is implemented as a Cloudflare Pages Function in `functions/api/quote.js`.

Set these server-side environment variables in the Cloudflare Pages project before deploying:

- `QUOTE_WEBHOOK_URL`: the Webhook URL from Grok Bot Quote form intake
- `QUOTE_WEBHOOK_AUTH`: the complete Authorization header value from Grok Bot Quote form intake

These values are server-only secrets. Do not prefix them with `PUBLIC_`, include them in client-side code, or commit them to Git. Redeploy the Pages project after adding or changing either variable.

## Deploying to cPanel/static hosting

1. Run `npm install` and `npm run build` on a local machine or build environment.
2. Open the generated `dist/` folder.
3. In cPanel, open **File Manager** and navigate to the domain’s document root (commonly `public_html/` or the directory assigned to `pacificspiritelectrical.ca`).
4. Upload the *contents* of `dist/` into that document root—not the `dist` directory itself.
5. Confirm that `index.html`, `robots.txt`, `sitemap-index.xml`, and the page folders are directly in the document root.
6. Visit the site and test the five navigation routes. Ensure the domain uses HTTPS.

Because this site is static, no Node.js runtime is needed on cPanel after the build files are uploaded.
